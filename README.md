# ขยับ-เลือก พิชิต NCDs

เกมเรียนรู้การป้องกันโรค NCDs สำหรับนักศึกษา เล่นด้วยกล้องเว็บแคมผ่านเว็บเบราว์เซอร์

- `index.html` — หน้ารวมเกม
- `burn.html` — ด่าน 1 เผาผลาญชานม (สควอท / กระโดดตบ)
- `life.html` — ด่าน 2 ชีวิตนักศึกษา 4 ปี (เอียงหัวเลือกคำตอบ)

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository แบบ Public แล้วอัปโหลดไฟล์ทั้ง 3 ไฟล์
2. Settings → Pages → Branch: `main` → Save
3. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

ต้องเปิดผ่าน https:// หรือ localhost เท่านั้นจึงจะใช้กล้องได้ (เปิดไฟล์โดยตรงด้วยการดับเบิลคลิกจะใช้กล้องไม่ได้)
แก้ไขเมนู/ค่าพลังงาน/สถานการณ์ได้ที่ส่วน "ตั้งค่า" ด้านบนของ `<script>` ในแต่ละไฟล์
